# FastAPI Mini Project 🚀

A lightweight, high-performance web API built with [FastAPI](https://fastapi.tiangolo.com/). This project serves as a robust backend foundation, featuring automatic interactive API documentation, fast execution, and easy-to-read code.

## ✨ Features

* **Lightning Fast:** Built on top of Starlette and Pydantic for top-tier performance.
* **Interactive API Docs:** Automatic Swagger UI generation (accessible at `/docs`).
* **Alternative API Docs:** Automatic ReDoc generation (accessible at `/redoc`).
